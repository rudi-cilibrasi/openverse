## `Prog.accepted`: everything a program accepted by the front end is guaranteed

`OpenVerse/Core/Guarantees.lean`; axioms: [propext, Classical.choice, Quot.sound]

```lean
@Prog.accepted : ∀ {P : Prog} {S : Sigs} {Γs : List (List VTy)} {τ : VTy},
  P.check = true →
    P.checkTypes S Γs = true →
      P.checkControl = true →
        S.fns[P.main]? = some ([], τ) →
          ∀ {r : Res} {out : List Nat},
            Runs P r out →
              r.scopeErr = false ∧
                r ≠ Res.err ErrKind.type ∧
                  r ≠ Res.err ErrKind.control ∧
                    (∃ fr heap,
                        Eval P Prog.initSt (Expr.call P.main []) r { fr := fr, g := { out := out, heap := heap } } ∧
                          HeapOK S heap ∧ ∀ (v : Value), r = Res.ok v → hasTy (tagsOf heap) v τ = true) ∧
                      (∀ (fn : Fn), P.fns[P.main]? = some fn → fn.decides = false → r ≠ Res.fail) ∧
                        ∀ (r' : Res) (out' : List Nat), Runs P r' out' → r' = r ∧ out' = out
```
