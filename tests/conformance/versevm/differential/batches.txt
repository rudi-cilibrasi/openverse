# Sessions for the differential corpus (#724): one batch per line, `NN: probe ...`,
# for `ovprobe.py generate --mode batch` (driver layout) after the probes are compiled one at a
# time; leave out of a batch any probe the compiler refuses. At most 15 probes and about 50
# OpenVerse lines per batch (begin/end markers not counted). Batches 09-12 hold one probe each
# and come last: a runtime error ends the session's Verse (ctl-err-call raises one by design;
# float-round-edges and int-tostring-min may hit a native's range check), and
# str-replace-all-empty may never return.
#
# Probes whose admission by 43.12 is itself in question (each alone on its form, so a refusal
# answers it): rat-ordering, prec-compare-chain, prec-compare-result, eq-different-types,
# eq-empty-values, tup-array-compare, param-array-pack, param-tuple-pack, param-override-default,
# case-string, case-no-default-fails, struct-field-set, misc-commas-in-blocks,
# misc-indented-comment, for-failing-body, arr-set-value, str-interp-nested.
#
# OpenVerse runs every batch in the driver layout (`generate --host openverse`) with the same
# lines as its single runs, except ovl-operator (batch 07), which it runs only alone: operators
# a program defines inside a module are not found by OpenVerse (LANGUAGE.md, Overloading:
# "at the top level"); Epic compiles it in the driver's module.
